# Zomato Restaurant Analysis 🍽️

## 📌 Project Overview
This project presents an end-to-end exploratory and business analysis of Zomato restaurant data, covering **restaurant ratings, cuisines, and cost patterns**. The goal is to uncover insights into customer preferences, pricing trends, and restaurant performance across different cuisines and locations — helping stakeholders make data-driven decisions around menu strategy, pricing, and market positioning.

## 🎯 Objectives
- Analyze restaurant ratings distribution and identify factors driving higher ratings
- Explore cuisine-wise popularity and performance trends
- Study cost-for-two patterns and their relationship with ratings and cuisine type
- Identify top-performing restaurants and cuisines by rating and affordability
- Build interactive dashboards for business/stakeholder decision-making

## 📁 Repository Structure
```
Zomato-Restaurant-Analysis/
│
├── assets/       # Images, logos, dashboard screenshots
├── data/         # Raw and cleaned Zomato dataset(s)
├── docs/         # Documentation, data dictionary, reports
├── excel/        # Excel-based analysis, pivot tables, charts
├── powerBI/      # Power BI dashboard (.pbix) files
├── sql/          # SQL scripts for data cleaning & querying
└── tableau/      # Tableau workbook(s) for visualization
```

## 🛠️ Tools & Technologies
- **Excel** – Data cleaning, pivot tables, exploratory analysis
- **SQL** – Data querying, aggregation, and transformation
- **Power BI** – Interactive dashboard for ratings, cost & cuisine insights
- **Tableau** – Visual storytelling and geographic/cuisine analysis

## 📊 Key Analysis Areas
| Area | Description |
|------|-------------|
| Ratings Analysis | Distribution of ratings, top & bottom-rated restaurants |
| Cuisine Analysis | Most popular cuisines, rating comparison by cuisine |
| Cost Analysis | Cost-for-two trends, price vs. rating correlation |
| Restaurant Performance | Best value-for-money restaurants and outliers |

## 📈 Dashboards
Interactive Power BI and Tableau dashboards are included in their respective folders, visualizing rating trends, cuisine popularity, and cost distribution across restaurants.

## 🚀 How to Use
1. Clone this repository
2. Explore raw/cleaned data in the `data/` folder
3. Run SQL scripts in `sql/` for querying and transformations
4. Open the Power BI (`powerBI/`) or Tableau (`tableau/`) files to view dashboards
5. Refer to `docs/` for detailed methodology and data dictionary
